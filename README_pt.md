#### Descrição

Jimi-Notes, a nota de papel quente na sua área de trabalho. Aplicativo de notas de desktop gratuito e ultraleve. Pacote de instalação apenas ~6MB, uso de memória <30MB, notas independentes de múltiplas janelas, cores personalizadas, salvamento automático, puramente offline sem upload (ainda não é código aberto).

#### Funcionalidades

- 🪶 **Leve e eficiente** - Pacote de instalação apenas ~6MB, uso de memória <30MB
- 🎨 **Cores personalizadas** - Defina livremente a cor de fundo e texto das notas
- 🪟 **Janelas independentes** - Cada nota é uma janela independente, sem interferências
- 💾 **Salvamento automático** - O conteúdo é salvo automaticamente em tempo real
- 🔒 **Puramente offline** - Zero upload, zero rastreamento, dados armazenados completamente localmente
