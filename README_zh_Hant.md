# Jimi-Notes 基米便簽

#### 介紹

基米便簽 Jimi-Notes，桌面上的暖紙小貼。免費、極致輕量的桌面便簽應用。安裝包僅 ~6MB，運行記憶體 <30MB，多視窗獨立便簽、自訂配色、自動儲存，純離線零上傳（當前暫未開源）。

#### 功能特點

- 🪶 **輕量高效** - 安裝包僅 ~6MB，運行記憶體 <30MB
- 🎨 **自訂配色** - 自由定義便簽背景和文字顏色
- 🪟 **多視窗獨立** - 每個便簽獨立視窗，互不干擾
- 💾 **自動儲存** - 內容即時自動儲存，無需手動操作
- 🔒 **純離線** - 零上傳、零追蹤，資料完全本地儲存
