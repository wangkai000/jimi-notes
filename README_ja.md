#### 紹介

Jimi-Notes、デスクトップ上の暖かい紙シール。無料、超軽量なデスクトップ付箋アプリ。インストールパッケージ량은約6MB、メモリ使用量 <30MB、マルチウィンドウ独立付箋、カラーカスタマイズ、自動保存、完全にオフラインでアップロードゼロ（現在未オープンソース）。

#### 機能特徴

- 🪶 **軽量高效** - インストールパッケージ量は約6MB、メモリ使用量 <30MB
- 🎨 **カラーカスタマイズ** - 付箋の背景とテキストの色を自由に定義
- 🪟 **マルチウィンドウ独立** - 各付箋は独立ウィンドウで、干渉しない
- 💾 **自動保存** - コンテンツはリアルタイムで自動保存、手動操作不要
- 🔒 **完全オフライン** - アップロードゼロ、トラッキングゼロ、データは完全にローカル保存
