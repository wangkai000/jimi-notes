#### Description

Jimi-Notes, le petit papier chaleureux sur votre bureau. Application de notes de bureau gratuite et ultra-légère. Paquet d'installation seulement ~6MB, utilisation mémoire <30MB, notes multi-fenêtres indépendantes, couleurs personnalisées, sauvegarde automatique, pur hors ligne zéro upload (pas encore open source).

#### Fonctionnalités

- 🪶 **Léger et efficace** - Paquet d'installation seulement ~6MB, utilisation mémoire <30MB
- 🎨 **Couleurs personnalisées** - Définissez librement la couleur de fond et du texte des notes
- 🪟 **Fenêtres indépendantes** - Chaque note est une fenêtre indépendante, sans interférence
- 💾 **Sauvegarde automatique** - Le contenu est sauvegardé automatiquement en temps réel
- 🔒 **Pur hors ligne** - Zéro upload, zéro suivi, données stockées entièrement en local
