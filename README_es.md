#### Descripción

Jimi-Notes, la nota de papel cálida en tu escritorio. Aplicación de notas de escritorio gratuita y ultraligera. Paquete de instalación solo ~6MB, uso de memoria <30MB, notas independientes de múltiples ventanas, colores personalizados, guardado automático, puramente sin conexión sin carga (todavía no es código abierto).

#### Características

- 🪶 **Ligero y eficiente** - Paquete de instalación solo ~6MB, uso de memoria <30MB
- 🎨 **Colores personalizados** - Define libremente el color de fondo y texto de las notas
- 🪟 **Ventanas independientes** - Cada nota es una ventana independiente, sin interferencias
- 💾 **Guardado automático** - El contenido se guarda automáticamente en tiempo real
- 🔒 **Puramente sin conexión** - Cero carga, cero seguimiento, datos almacenados completamente en local
