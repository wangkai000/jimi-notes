#### 介绍

基米便签 Jimi-Notes，桌面上的暖纸小贴。免费、极致轻量的桌面便签应用。安装包仅 ~6MB，运行内存 <30MB，多窗口独立便签、自定义配色、自动保存，纯离线零上传（当前暂未开源）。

#### 功能特点

- 🪶 **轻量高效** - 安装包仅 ~6MB，运行内存 <30MB
- 🎨 **自定义配色** - 自由定义便签背景和文字颜色
- 🪟 **多窗口独立** - 每个便签独立窗口，互不干扰
- 💾 **自动保存** - 内容实时自动保存，无需手动操作
- 🔒 **纯离线** - 零上传、零追踪，数据完全本地存储
