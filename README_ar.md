# Jimi-Notes ملاحظات جييمي

#### الوصف

Jimi-Notes، الملاحظة الورقية الدافئة على سطح المكتب. تطبيق ملاحظات مجاني وخفيف للغاية. حجم التثبيت فقط ~6MB، استخدام الذاكرة <30MB، ملاحظات مستقلة متعددة النوافذ، ألوان مخصصة، حفظ تلقائي، دون اتصال كامل بدون رفع (غير مفتوح المصدر بعد).

#### الميزات

- 🪶 **خفيف وفعال** - حجم التثبيت فقط ~6MB، استخدام الذاكرة <30MB
- 🎨 **ألوان مخصصة** - حدد ألوان الخلفية والنص للملاحظات بحرية
- 🪟 **نوافذ مستقلة** - كل ملاحظة في نافذة مستقلة بدون تداخل
- 💾 **حفظ تلقائي** - يتم حفظ المحتوى تلقائيًا في الوقت الفعلي
- 🔒 **دون اتصال كامل** - بدون رفع، بدون تتبع، البيانات مخزنة محليًا بالكامل
