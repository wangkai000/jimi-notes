# Jimi-Notes 지미 노트

#### 설명

Jimi-Notes, 데스크톱 위의 따뜻한 종이 스티커. 무료, 초경량 데스크톱 메모 앱. 설치 패키지 약 6MB, 메모리 사용량 <30MB, 멀티창 독립 메모리, 사용자 정의 색상, 자동 저장, 완전 오프라인 업로드 제로 (현재 오픈 소스 아님).

#### 기능

- 🪶 **경량 효율** - 설치 패키지 약 6MB, 메모리 사용량 <30MB
- 🎨 **사용자 정의 색상** - 메모 배경과 텍스트 색상을 자유롭게 정의
- 🪟 **독립 창** - 각 메모는 독립 창으로 서로 간섭 없음
- 💾 **자동 저장** - 콘텐츠가 실시간으로 자동 저장, 수동 조작 불필요
- 🔒 **완전 오프라인** - 업로드 제로, 추적 제로, 데이터가 완전히 로컬에 저장
